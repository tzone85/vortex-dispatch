# VXD Obsidian Vault

This folder is an [Obsidian](https://obsidian.md) vault: a set of interlinked
Markdown notes documenting the Vortex Dispatch (VXD) project. Open this folder
(`docs/obsidian/`) as a vault in Obsidian to get backlinks, graph view, and tag
search.

Start at **[[VXD MOC]]** — the map of content that links to everything else.

## Conventions
- Wikilink-style links (double square brackets) connect notes; hover-preview and the graph view rely on them.
- `#tags` (e.g. `#security`, `#architecture`, `#operations`) group related notes.
- Each note is self-contained but links to source files using paths relative to
  the repo root (e.g. `internal/engine/monitor.go`).
